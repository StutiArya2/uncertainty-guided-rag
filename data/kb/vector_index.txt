A vector index accelerates nearest-neighbour search over embedding collections. Exact search compares the query against every stored vector, which is linear in collection size but always returns the true nearest neighbours. Approximate methods such as HNSW and IVF trade a small amount of recall for large speed gains. For collections below roughly ten thousand vectors, exact brute-force search is usually fast enough and avoids the tuning burden entirely. Choosing an approximate index too early is a common source of unexplained recall loss.
