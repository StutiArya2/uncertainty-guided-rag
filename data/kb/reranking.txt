Reranking applies a slower, more accurate model to the shortlist produced by fast first-stage retrieval. Cross-encoders score a query and document jointly, letting every query token attend to every document token, which is far more accurate than comparing independent embeddings. The cost is that cross-encoders cannot be precomputed, so they only run over a shortlist. A typical configuration retrieves one hundred candidates and reranks them down to five. Reranking usually improves precision substantially at modest latency cost.
