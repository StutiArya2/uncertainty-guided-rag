Tokenization converts raw text into the discrete units a model processes. Byte-pair encoding merges frequent character pairs into single tokens, keeping vocabularies compact while still representing any string. Token counts are not proportional to word counts, and they vary substantially between tokenizers for the same text. Estimating token cost from character counts is convenient but imprecise, and any efficiency claim should be measured with the actual tokenizer. Different models can report meaningfully different token counts for identical input.
